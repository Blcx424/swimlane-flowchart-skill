# 出图前自检清单与常见坑

交付 SVG 与 PNG 之前逐项自检。任何一项不满足先修再交付。

## 结构与内容

- [ ] 总标题存在且居中
- [ ] 阶段泳道数为 3 到 4，阶段名清晰
- [ ] 每个阶段节点组齐全，无遗漏
- [ ] 衔接箭头方向正确，标签与阶段对应
- [ ] 回环 / 强调框（如有）表达正确

## 数据

- [ ] 所有数字与用户素材一致
- [ ] 无编造指标
- [ ] 单位正确（如 μm、%、N、mm）

## 视觉

- [ ] 绘制顺序正确：背景、箭头、节点、文字
- [ ] 无文字被框线或箭头遮挡
- [ ] 字号足够大，缩到 PPT 仍可读
- [ ] 配色统一，一套主题不混用
- [ ] 同类图尺寸一致，便于并排或平分页面

## 交付

- [ ] SVG 与 PNG 都已生成
- [ ] PNG 为 2x 清晰度
- [ ] 命名符合 figX-X_名称 格式

## 常见坑

1. 先画节点再画箭头，箭头被节点浅色底盖住。牢记顺序：背景 → 箭头 → 节点 → 文字。
2. 字号偏小，投影后看不清。宁可偏大，内容过多时删内容而不是缩字号。
3. 内容堆得太多导致拥挤。出精简版，合并同质条目、只留结论。
4. 数字想当然随手填。必须回查用户素材，不编造、不模糊。
5. 同一个小节多张图比例不一致，PPT 排版错位。同类图保持同画布尺寸。
6. 文字压在虚线上没有白描边垫底，被线穿过。用 paint-order: stroke 加白色描边。
7. 数学变量用了中文字体，样式不统一。变量用斜体衬线字体。
8. 渲染时忘了 2 倍清晰度，贴到 PPT 变模糊。统一加 --force-device-scale-factor=2。
